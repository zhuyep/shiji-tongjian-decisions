## 2. 交付物

1. 一份 Markdown 推演报告：约束与价值排序 → 三条路径表 → 史记/通鉴对照 → **离线核验结果**（`exact` / 缺口明说）→ 一个最小下一步

## 3. 如何下单与收款对账

| 步 | 谁 | 动作 | 对账痕迹 |
| --- | --- | --- | --- |
| A 意向 | 用户 | 在相关公开帖下或 X 私信 @zhuy1043 回「试」 | 马仔记入意向台账（日期/渠道/一句话场景） |
| B 说明 | 马仔 | 发本页链接 + 脱敏清单 | 发出记录 |
| C 授权 | **董事长** | 确认接单与收款方式（人闸；助手不自收） | 授权备注 |
| D 收款 | 董事长指定账户 | 用户付款 | **收款凭证**（截图/流水号）归档 |
| E 交付 | 马仔 | 交报告+讲解 | 交付文件哈希或仓内私有笔记路径 + 完成日 |
| F 对账 | 马仔+计划部 | 周报：意向数 / 成交数 / 实收金额 | OPC 或打星看板「变现试验」栏 |

**成功标准（本试验）：** ≥3「试」意向；≥1 愿约；若成交则凭证可核对到金额与日期。
