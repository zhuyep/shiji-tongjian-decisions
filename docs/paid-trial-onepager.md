## 1. 路径（怎么从公开仓走到收款）

1. **发现：** 自然 Star + awesome 发现面 PR（BehiSecc / 中文列表 / karanb192 / shishirui）+ X 曝光帖。  
2. **信任：** 公版示例可自测（[晋升](../examples/promotion-decision.zh-CN.md) · [跳槽](../examples/job-switch-decision.zh-CN.md)）；引文可离线核验。  
3. **意向：** 相关公开帖下或 X 私信 @zhuy1043 回「试」→ 记入意向台账。  
4. **说明：** 马仔发本页链接 + 脱敏清单（约束 / 价值排序 / 不可接受代价）。  
5. **人闸：** **董事长**确认接单与收款方式（助手不自收）。  
6. **收款 → 交付：** 凭证归档后交 Markdown 报告 + 约 30min 讲解；对账进 OPC「变现试验」栏。
