# 史鉴人生抉择

帮助用户看清可选路径及其代价，保留最终选择权。史书提供有条件的类比与警示，不是命运预测、人物测评或现代决策的因果证明。

## 先界定现实问题

用一句话描述“谁在什么约束下，为哪些价值，必须在何时做哪项选择”。从对话提取目标、底线、现有选项（含维持现状）、可控资源、相关人的利益、时间窗口、退出成本、已知证据与关键未知；缺失值标未知。

只问会改变判断的关键缺口，其余明确假设后继续。用户尚未给具体困境时，请其提供处境和纠结的选项，不从用户的项目、日历或私人文件自行构造人生问题。

## 锁定古籍来源

先读 [来源与检索](references/sources.md) 和 [古籍库配置](references/library.json)。本技能的特定古籍就是《史记》《资治通鉴》，资料网站是访问渠道，不要求用户另选网站。只从这两书正文形成历史案例证据；现代文章、参考项目、其他书籍和模型记忆只可作检索线索。用户另行指定版本/文件时优先遵守。

默认优先访问维基文库，可改用中国哲学书电子化计划或用户提供的两书文本，并注明本次版本。在线按卷检索；本地缓存仅是已取回的片段，不能把缓存无结果写成两书无案例。没有可访问原文时，交付现实问题框架和待核源线索，明确“数据源不可用”，不填补引文与历史结局。

参考项目和 [案例导航](references/case-index.md) 只帮助生成检索词，不是历史证据。实际使用案例必须重新打开正文或验证有来源、哈希和定位信息的缓存。导航不是穷尽目录，检索不能停在三个熟悉人物。

## 按场景内核找案例

读 [匹配与推演方法](references/method.md)。先抽象选择结构，再用古代措辞、人物、事件和异体字扩大召回；检索有利于不同选项的材料。现代词语搜不到，不等于古籍无相近结构。

选少量最有解释力的案例，通常 2–4 个。逐案说明相似点、决定性的差异、证据缺口和采用/淘汰理由。可只用一书；不为凑两书或一正一反牺牲匹配度。优先寻找能挑战初步倾向的案例；未找到就列出检索范围与结论限制。

同一事件在两书出现，算同一事件簇；《通鉴》可能承用《史记》，不可作为两次独立成功或独立印证。不能把“某人也辞官”当作结构匹配，也不能把“老板＝君主、同事＝政敌”当作既定事实。

## 还原决策，再打开结局

对每个采用的案例，按 [结构化记录](references/record.md) 整理：

1. **决策截面**：明确时间节点、角色、利益、约束；只使用彼时可得的信息。史书的回溯叙事和人物对话要分别标明，不能视为经过独立核实的心理记录。
2. **选项与判断**：区分史料明载的方案、根据当时约束推断的可行替代、仅供讨论的反事实。给出实际所选路径、记载的理由、分析推断，以及哪些选项实际上无权或无力实施。
3. **结果与代价**：再读后续记载。分别列即时与长期结果、显性与隐性代价、承担者、可逆性；区分当时预期与后来发生。未记载的成本写未知，不写零。
4. **证据**：每项关键历史主张绑定具体引文、卷篇/纪年/段落和链接或文件位置。人物自述、叙述者记载、史家评论分开。

关键标签使用「史料记载」「史家评论」「分析推断」「反事实假设」「待核实」。引文原样保留；转述不加引号。文本匹配成功只证明该版本有这句话，还要人工检查该段是否支持所述主张、是否属于该发言者与决策时点；不能因此证明叙述真实、史家无偏见或所归因果成立。

## 迁回今天做分支推演

先列现代制度、法律、资源、家庭责任和退出渠道等差异，判断哪些历史机制还可能适用。没有足够信息支持他人动机时，给竞争性解释和可以区分解释的事实，不诊断对方人格或恶意。

比较用户真实可选的路径：预期收益、即时/长期代价、对第三方的影响、可逆性、触发条件，以及哪个未知量最可能改变排序。对关键路径描述有利、基准、不利条件下的演变；这是条件性情景，不是概率预测。历史案例数、检索分数、模型语气都不能转成成功率。

结尾给出：
- **条件性启发**：在条件 C 下，机制 M 可能使选择 A 出现后果 R；附支持、反例或反证不足与失效条件。
- **风险提醒**：最坏且难逆的损失、隐性成本、转嫁给他人的负担，以及被故事掩盖的现代约束。
- **最小下一步**：能增加信息或保留选择权的动作、观察信号和复盘节点。若用户要建议，可给依据明确的暂定倾向及推翻它的条件，不代替用户设定人生价值。

一个案例只能提出假说。即使有多个案例，也不称普遍规律；史书样本有幸存者偏差、精英偏差和编纂立场。必要时明确“现有材料不足以给出倾向”。

## 输出与工具

默认中文，先交代本次判断与不确定性，再按“现实抉择—历史对照—路径比较—启发与风险—出处”展开。篇幅按问题调整，完整字段保留在案例记录中；不必给每次短答附整套表格。要求结构化导出时采用 [record.md](references/record.md) 的 JSON 结构。

本地 UTF-8 原文可用 `scripts/corpus.py` 建立带来源哈希的卷篇记录、检索、核验引文；命令见来源说明。脚本不代替语义匹配、因果判断或史源批判。不要一次读取两书全文。

维护或复盘设计时再读 [设计来源与取舍](references/design-provenance.md)；普通推演不必加载。

现实行动涉及当前法律、医疗、投资等专业事实时，历史启发与现代证据分列，按宿主规则核验当前事实；古籍不能作此类行动的唯一依据。
