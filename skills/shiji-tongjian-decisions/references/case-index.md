# 已核源案例导航

初版仅用下列三个决策截面验证方法。它们不是全部适用案例，也不是预先给用户准备的答案；有新问题应继续检索两书。原文缓存见 `sample-corpus/manifest.json`，逐案引用前用 corpus.py 验证。

| 案例/事件簇 | 检索入口与原文 | 可讨论的内核 | 不能据此推出 |
| --- | --- | --- | --- |
| 范蠡辞越／越灭吴后的去留 | 史记卷四十一《越王勾践世家》；范蠡、君行令、私徒屬、輕寶；source ID `shiji-041` | 旧目标已实现后，对地位、依赖、自主性的重新取舍；退出资源与退出成本 | 骨干必被猜忌；辞职必成功；文种若走就必活 |
| 张良受封与后续责任／汉初封功臣与储位争议 | 史记卷五十五《留侯世家》；不敢當三萬戶、杜門、劫留侯、行少傅事；source ID `shiji-055` | 放弃额外奖赏、缩小参与范围，却仍有关系义务；退出不是二元开关 | 张良完全远离政治；只靠少争就能安全；装病/辟谷值得模仿 |
| 吴起离魏入楚／魏楚转换及楚悼王身后变局 | 资治通鉴卷一《周纪一》安王十五年条追叙及二十一年条；吳起、懼誅、遂奔楚、貴戚、大臣；source ID `tongjian-001` | 更换环境可带来机会，同时引入新的关键人物依赖与反对者 | 离开坏环境没用；去留本身单独造成后来结果 |

范蠡与文种同属一事件簇，比较有启发，但不是两个独立样本；范蠡在齐再辞相是另一个时点，不能把齐国散财冒记为辞越的成本。吴起的长期遭遇发生在新角色及改革之后，不能直接归因于最初离魏。

遇到纯情绪、亲密关系、医疗或现代投资问题，先看结构是否匹配；这些政治精英案例很可能不合适。没有近例时保留现代问题分析，不把故事强塞进来。
