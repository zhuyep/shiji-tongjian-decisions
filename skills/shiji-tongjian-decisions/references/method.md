# 匹配与推演方法

## 场景内核

把现实叙述拆成下列维度，按对本次选择的影响取舍；不量化成伪精确总分。

| 维度 | 要弄清的事 | 影响匹配的差异 |
| --- | --- | --- |
| 核心张力 | 安全/成长、承诺/退出、眼前/长期、个人/共同体等 | 用户价值排序不同会改变最优路径 |
| 角色与权力 | 谁能承诺、分配、否决、退出；本人有多少自主权 | 有名位但没有实际权力，不同于真正控制资源 |
| 依赖与筹码 | 收入、技能、关系、信誉是否可迁移 | 同样被依赖，资源独占与可替代会导致不同路径 |
| 信息与信任 | 可观察事实、传闻、不可验证承诺各是什么 | 不能由一次不快推断长期敌意 |
| 时序与窗口 | 环境在哪个具体转折；行动有何先后约束 | 不机械套王朝兴衰五阶段 |
| 退出与可逆性 | 是否可小步试探、返回、转向；锁定成本多大 | 古代难以人身退出，现代可能有合同与劳动保障 |
| 利益承担 | 本人、家属、合作者、公众分别付什么成本 | 帝王将相的得失可能建立在他人损失之上 |
| 制度与资源 | 法制、财产、身份、通信、流动性、社会保障 | 致命差异可直接淘汰看似精彩的故事 |

先写一条结构句，例如：“在承诺保障不足、关键资源依附于原组织的条件下，是否现在退出，以换取自主性，同时承担现金流与关系损失。”这是分析描述，不是关于任何历史人物的断言。

## 两阶段检索

**召回**：现代处境 → 机制词 → 古代用语/异体词 → 候选人物事件 → 原文。针对去留，可检索辞、去、留、退、归/歸、仕、患、功等，但单字噪声很大，应与人物、篇名或具体短语组合。范蠡、张良、韩信、李斯等熟知人名只能作候选线索；不得不经检索就写入结果。允许从正文发现不知名案例。

**筛选**：逐一核对核心张力、权力依赖、退出条件、信息及时序。证据支持的关键结构一致且差异不推翻机制，才可采用；只在情节、情绪或人物标签上相似的降为背景或淘汰。保留候选表：案例、事件簇、匹配依据、关键差异、原文获取状态、采用理由。

检索日志记录本次库/版本、查询词（含变体）、检索卷篇或在线查询、命中与排除理由。没有命中时逐步改用异体字、同义词和篇章定位，仍失败再标“本次范围内未找到”；不得把有限检索写成全书穷尽。

## 决策时间防线

每案固定一个节点 t0；t0 后的结果单列。提醒读者史书本身是事后撰写的，因此“当时已知”最好写成“据本段记载，此时人物获知/被告知……”。对话是史家记录的对话，不是录音；劝说者的预言是论证，不等于已发生事实。

有依据的替代选项需要可行性检查：当时是否有权行动、资源、时间、退出渠道；是否只是后世读者才知道的机会。不可行的“完美选项”不得用于指责当事人。

每案至少区分：
- **所选方案**：有行为记载；
- **未选方案**：明确区分有人提出过，还是分析者重建；
- **所给理由**：人物自述、他人归因、史家评论、现代解释各自署名；
- **未走路径**：结局不可观察，不用另一个人的成功证明此人照做必然成功。

## 代价矩阵

按“成本类型 × 证据性质”分别记录，不把隐性和推测当同义词。

| 字段 | 取值/含义 |
| --- | --- |
| 可见性 | 显性：金钱、职位、时间、惩罚等可直接观察；隐性：选择权、信任、身份、承诺负担、对他人的压力等 |
| 证据性质 | 史料记载 / 史家评论 / 分析推断 / 反事实假设 / 待核实 |
| 时态 | 当时预期 / 后来发生 / 未发生的情景风险 |
| 承担者 | 本人、家属、伙伴、组织、第三方；不能用主角获利覆盖他人损失 |
| 时间与可逆性 | 即时/中期/长期；可逆/部分可逆/难逆/未知 |
| 机会成本 | 放弃了什么；没有资料就未知，不虚构财富、内心痛苦或健康状态 |

历史中的金钱、年限、死亡等精确数字须有原文依据。现代隐性成本应尽量对应可观察变量，如退出后资源能否继续使用、照护责任是否有人接替。

## 条件性归纳与反例

支持案例与反例可以揭示不同前提，不能简单按输赢各选一个。列出哪些条件让同类行为得到不同结果，并主动检查逆向因果、资源差异、外部冲击、对手反应、选择偏差等解释。

同一场景中不同人的命运有比较价值，但不是彼此独立的因果实验。同一事件由两书转述也不会增加独立样本量。表述限于“这些材料提示，应检查……”，不宣称统计频率。

## 现代分支

只比较现实可执行的选项。保留现状也有成本；“退出”可以分为准备退出、分段退出、立即退出，前提是用户确有这些渠道。

各选项列：适用条件 → 可能演变 → 早期信号 → 显性/隐性成本与承担者 → 可逆步骤 → 停止/重评条件。乐观/基准/不利场景必须说清由哪些变量驱动；不能机械生成三个故事来假装预测。

建议的价值排序来自用户。如果安全、收入、家庭、成长等互相冲突，展示排序变化如何改变建议，而不是给一个统一人生答案。约定复盘点可以作为建议写出；不要因此自动创建提醒。
