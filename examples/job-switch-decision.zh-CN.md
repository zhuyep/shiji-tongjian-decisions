# 现实抉择

**演示输入（虚构）**：我在现组织工作数年，绩效尚可，收入与节奏可维持家庭底线。近期收到一份外部 offer：薪资更高、职级相近，但团队与授权尚未见清；试用期后回退到原组织的可能性很低。我也试过在内部谈换组或减负，对方只口头表示“以后再说”。我更看重可预期的工时、专业成长与可带走的能力积累。我该立刻接受 offer、继续内部协商并观察，还是先稳住现状、把外部选项核实到可签合同再动？

**暂定判断**：先把外部机会的职责、汇报线、试用期与裁撤规则核实到可写进合同，并盘点离开后的现金流与可迁移作品；同时给内部协商设一个明确期限。当前证据不足以支持“立刻跳”或“永远不跳”。这个判断首先来自输入中的价值排序与信息缺口；历史案例用于找出容易漏算的退出成本与新依赖。

场景内核：换组织可能缓解旧环境的停滞，也可能把支持押在新老板或新项目上；用户要在稳定、成长、自主性与家庭底线之间取舍。关键未知包括新岗真实工时、授权是否个人化、试用期失败成本、内部协商是否可落地，以及离开后多久能重建等效收入。

# 检索与筛选

限定两书。先以“去留/归、奔/赴、辞/不受、患/疑、相/任”等概念查找，再用人名与短语定位。候选包括范蠡辞越（及后来在齐再辞）、吴起离魏入楚、张良受封后仍被强求参与；文种只作为范蠡同一事件簇中的对照。

三个案例都涉及离开或换环境，但时代、人身安全、权力来源与现代雇佣合同不同，迁移适用度有限。尤其吴起面临惧诛，演示用户没有相似证据，故只能用来检查新环境依赖与支持者风险，不能把它当“现雇主危险”的证明。张良并未在受封节点彻底离场，用来检查“留下但减负”是否真能减负，而不是证明跳槽必然更好。

本次没有穷尽两书，没有亲自运行参考项目的完整系统。实际缓存与来源哈希见 [原文清单](../skills/shiji-tongjian-decisions/references/sample-corpus/manifest.json)，13 条逐字核验记录见 [证据记录](evidence.json)。下文证据段中的 F/Z/W 编号对应登记表里的 evidence_id；展示引文连同标点原样保留，并由离线测试检查文本和来源的一致性。这不证明历史解释或现代建议有效。

# 案例一：范蠡辞越——离开的理由与离开的条件要分开看

**节点**：越灭吴后，范蠡准备离开越国。

| 项目 | 拆解 |
| --- | --- |
| 当时可得信息 | 据史书记载，旧目标已实现；范蠡对君臣关系作出不宜久留的判断；勾践留人时同时提出分国与惩罚。这不是对现代上司的诊断。 |
| 明载选项 | 留下接受君主提出的安排；离开。史书没有证明“分国承诺”一定可兑现。 |
| 所选与理由 | 选择离开；原文将其判断写为大名难久居、患难与处安关系不同，并以“君行令，臣行意”回应。属于史书记述的人物判断，不是已被证实的普遍规律。 |
| 结果 | 记载其携轻宝和随从离越，后来在齐、陶重新经营生活；长期结果无法在离开时预知。 |
| 显性代价 | 离开既有职位与政治环境，重新迁居和经营；并非没有资产、帮手地从零开始。精确经济损失未记。 |
| 隐性代价 | 关系网络重建、身份改变、随行者承担不确定性，是据迁居行为作出的分析推断；具体心理感受未知。 |
| 反事实 | 留下是否必死未知。文种的结局不能证明范蠡留下也必然如此，两人角色与行动不完全相同。 |

证据（C1）：原文记其判断“范蠡以爲大名之下，難以久居，且句踐爲人可與同患，難與處安”[F4](evidence.json)，又以“君行令，臣行意。”[F1](evidence.json) 回应挽留，并“乃裝其輕寶珠玉，自與其私徒屬乘舟浮海以行，終不反。”[F2](evidence.json) 卷内另记在齐辞相散财，**不能把那笔后来的散财算成辞越时已支付的成本**。[《史记》卷四十一《越王勾践世家》，固定版本2018395](https://zh.wikisource.org/w/index.php?title=史記/卷041&oldid=2018395)。

对今天的启发：评估跳槽时应分开核对“为什么想走”与“走得动吗”——合法可带走的储备、作品、技能、支持与外部 offer 的可执行条款。演示输入里内部协商仍口头、外部授权未清，不支持“像范蠡一样立刻走”。

# 案例二：张良受封后的参与边界——留下减负，不等于义务消失

**节点**：汉六年封功臣，随后观察张良参与范围的变化。

| 项目 | 拆解 |
| --- | --- |
| 当时可得信息 | 原文记高帝允许自择齐地三万户；张良提出封留已足。不能用后来的政治事件证明他此时已准确预见一切。 |
| 明载选项 | 接受所提封赏；请求较小范围的封赏。完全离开政治并不是此节点史料明确给出的同等选项。 |
| 所选与判断 | 请求封留，表达足够之意。将其解释为降低风险可以讨论，但应标分析推断，不能替代人物所述理由。 |
| 结果 | 获封留侯；后来闭门减少参与，却仍被强求出谋，并履行少傅事务。再后有弃人间事的自述。 |
| 显性代价 | 没有选择更大的封赏方案；实际封地差额和经济现值不作计算。后续仍需投入政治事务。 |
| 隐性代价 | 声望和历史关系可能形成持续请求与义务；“少参与”未必等于有能力拒绝，这是依据后续被强求行为作出的推断。 |
| 未知/反事实 | 若接受更大封赏会怎样，原文不能回答；不能认定自限封赏单独造成其后结果。 |

证据（C2）：“臣願封留足矣，不敢當三萬戶。”[Z1](evidence.json) 后来记“呂后乃使建成侯呂澤劫留侯”[Z2](evidence.json)，又记“留侯行少傅事。”[Z3](evidence.json) 这些是不同时间点，按原文顺序保留。[《史记》卷五十五《留侯世家》，固定版本2666612](https://zh.wikisource.org/w/index.php?title=史記/卷055&oldid=2666612)。

对今天的启发：若选择“先不跳、内部谈减负或换组”，要谈的是可拒绝事项、承接人、复盘日期与回退安排，而不是只换一个较轻的头衔。演示场景中“以后再说”尚未构成可执行边界；也不能用张良证明“留下一定更安全”。

# 案例三：吴起离魏入楚——换环境可能解决旧问题，又引入新依赖

**节点**：吴起因在魏处境变化而离魏，赴楚任职。该段在《通鉴》安王十五年条内追叙，不据排版擅自精确到离魏之年。

| 项目 | 拆解 |
| --- | --- |
| 当时可得信息 | 原文叙述魏武侯对吴起生疑，吴起惧诛；文本还叙述他人设计，但不能假定吴起当时知道整个设计。 |
| 选项 | 实际去楚有记载；留下澄清、转赴其他国家只是分析重建，史料没有证明这些替代在当时可行。 |
| 所选与判断 | 离魏赴楚。惧诛是原文归于吴起的动因；不能附加未记载的精确收益计算。 |
| 结果 | 到楚受重用并推行措施；同段记贵戚大臣多怨。安王二十一年楚悼王去世后，吴起遭贵戚大臣攻击。 |
| 显性代价 | 放弃原有任职环境、赴另一国家。具体财务成本与家属影响未记。 |
| 隐性代价 | 新角色的支持可能依赖特定掌权者；改革触及利益并累积反对。前者为分析推断，后者有叙述依据。不能说他离魏时就必知后来结果。 |
| 因果边界 | 后来的遭遇还涉及楚国的制度、改革及支持者去世，不能只归因于离魏或“不够低调”。 |

证据（C3）：“魏武侯疑之而未信，起懼誅，遂奔楚。”[W1](evidence.json) 到楚后“楚悼王素聞其賢，至則任之為相。”[W4](evidence.json) 以及“而楚之貴戚大臣多怨吳起者。”[W2](evidence.json)；后段为“楚悼王薨，貴戚大臣作亂，攻吳起”[W3](evidence.json)。[《资治通鉴》卷一《周纪一》安王十五年条与二十一年条](https://zh.wikisource.org/wiki/資治通鑑/卷001)。本次网页未取得固定版本号，保留访问日期2026-09-21与本地快照哈希。

对今天的启发：外部 offer 除了薪资与职级，还要看资源、权责和支持是否绑在某一个老板、客户或项目上；试用期与组织变动会放大这种依赖。现代雇佣中的依赖不等同古代人身威胁。

# 现代选项推演

| 路径 | 合适的前提 | 显性与隐性成本 | 观察信号与重评条件 |
| --- | --- | --- | --- |
| 接受外部 offer | 职责、汇报线、试用期、裁撤与竞业条款清楚，且薪资/工时符合家庭底线；离开后的储备够覆盖空窗 | 失去原组织资历与内部网络；试用期失败回不去；新支持若个人化，支持者变动时风险上升 | 有利：授权与编制兑现、工时可预期；不利：职责持续外溢、唯一赞助人离开；触及预先约定的家庭、健康或现金流边界时重评 |
| 继续内部协商并设期限 | 组织确实允许换组/减负，且能在约定期限内写成可执行安排 | 可能错过当前 offer；口头承诺落空后沉没了等待时间；拒 offer 后外部窗口可能关闭 | 看能否明确不负责事项、谁承接溢出工作、何时书面复盘；到期仍只有“以后再说”，则此路径事实上不存在 |
| 暂缓跳槽、核实后再动 | 现状可维持家庭底线，且有精力把外部选项核到可签 | 学习与尽职调查的时间；暂缓涨薪的机会成本；组织若察觉求职，反应未知 | 外部条款、竞业、可迁移作品与现金流储备明朗后，再在“签/不签”之间选择；没有可执行外部选项时，不把“准备离开”误当成已经离开 |

本次不估成功率。不同价值排序会改变倾向：若短期现金与职级跃迁优先、且试用期风险可承受，接受 offer 会更有吸引力；若可预期工时与家庭底线不可让步，应先核实新岗边界与内部协商期限。历史故事不能替用户决定哪个价值更高。

# 条件性启发、风险和下一步

这些案例提示两项待检验机制：当退出能否成功依赖储备与外部条款时，离开的理由与离开的能力必须分开评估；当新机会的支持绑在特定个人或项目上时，换环境未必降低总风险。它们不是普遍规律或统计结论。

主要风险是把对现组织的不满升级成历史式猜忌，或只看古人最后的成败、漏掉途中代价与同行者的负担；另一风险是把“口头减负”当成已完成的留下方案。三个精英案例不能代表普通人的所有选择。

最小下一步：列出家庭现金流与可接受空窗月数；把外部 offer 的职责、汇报、试用期与竞业问到可写进合同；给内部协商写一个到期日与书面产出。新信息取得后再比较三条路径。没有证据时，保留“尚不足以决定”，也是一个合格结论。
