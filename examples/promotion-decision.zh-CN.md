# 现实抉择

**演示输入（虚构）**：我在一个组织多年，收入稳定，近期被邀请晋升，收入会增加，但职责和下班后投入没有说清。我更重视家庭时间与稳定收入，也想保持专业成长。目前没有明确的外部机会。我该接受、争取较小职责，还是准备离开？

**暂定判断**：先核实晋升的真实责任与资源，并争取有边界的方案。当前证据不足以支持立即接受或立即离开。这个判断首先来自输入中的价值排序与信息缺口；历史案例用于找出容易漏算的成本。

场景内核：增加收入与地位可能同时增加责任和组织依赖；用户要在稳定、时间、自主性、成长之间取舍。关键未知包括增加的实际工时、可用团队与授权、能否回退、家庭现金流底线及外部机会。

# 检索与筛选

限定两书。先以“受封/不受、去留/归、责任/请、升迁/相、患/疑”等概念查找，再用人名与短语定位。候选包括范蠡辞越、张良受封后逐步减少参与、吴起离魏入楚；文种只作为范蠡同一事件簇中的对照。

三个案例都涉及角色或环境转换，但时代、人身安全、权力来源与现代就业不同，迁移适用度有限。尤其吴起面临惧诛，演示用户没有相似证据，故只能用来检查新环境依赖，不能把它当“现组织危险”的证明。

本次没有穷尽两书，没有亲自运行参考项目的完整系统。实际缓存与来源哈希见 [原文清单](../skills/shiji-tongjian-decisions/references/sample-corpus/manifest.json)，13 条逐字核验记录见 [证据记录](evidence.json)。

# 案例一：范蠡辞越——退出既要有理由，也要有条件

**节点**：越灭吴后，范蠡准备离开越国。

| 项目 | 拆解 |
| --- | --- |
| 当时可得信息 | 据史书记载，旧目标已实现；范蠡对君臣关系作出不宜久留的判断；勾践留人时同时提出分国与惩罚。这不是对现代上司的诊断。 |
| 明载选项 | 留下接受君主提出的安排；离开。史书没有证明“分国承诺”一定可兑现。 |
| 所选与理由 | 选择离开；原文将其判断写为大名难久居、患难与处安关系不同。属于史书记述的人物判断，不是已被证实的普遍规律。 |
| 结果 | 记载其携轻宝和随从离越，后来在齐、陶重新经营生活；长期结果无法在离开时预知。 |
| 显性代价 | 离开既有职位与政治环境，重新迁居和经营；并非没有资产、帮手地从零开始。精确经济损失未记。 |
| 隐性代价 | 关系网络重建、身份改变、随行者承担不确定性，是据迁居行为作出的分析推断；具体心理感受未知。 |
| 反事实 | 留下是否必死未知。文种的结局不能证明范蠡留下也必然如此，两人角色与行动不完全相同。 |

证据：原文记载“乃裝其輕寶珠玉，自與其私徒屬乘舟浮海以行，終不反”。卷内另记在齐辞相散财，**不能把那笔后来的散财算成辞越时已支付的成本**。[《史记》卷四十一《越王勾践世家》，固定版本2018395](https://zh.wikisource.org/w/index.php?title=史記/卷041&oldid=2018395)。

对今天的启发：评估退出方案时应盘点合法可带走的储备、能力、支持与外部机会；演示输入没有这些证据，不支持“像范蠡一样立刻走”。

# 案例二：张良受封后的参与边界——少要奖赏不等于没有后续义务

**节点**：汉六年封功臣，随后观察张良参与范围的变化。

| 项目 | 拆解 |
| --- | --- |
| 当时可得信息 | 原文记高帝允许自择齐地三万户；张良提出封留已足。不能用后来的政治事件证明他此时已准确预见一切。 |
| 明载选项 | 接受所提封赏；请求较小范围的封赏。完全离开政治并不是此节点史料明确给出的同等选项。 |
| 所选与判断 | 请求封留，表达足够之意。将其解释为降低风险可以讨论，但应标分析推断，不能替代人物所述理由。 |
| 结果 | 获封留侯；后来闭门减少参与，却仍被强求出谋，并履行少傅事务。再后有弃人间事的自述。 |
| 显性代价 | 没有选择更大的封赏方案；实际封地差额和经济现值不作计算。后续仍需投入政治事务。 |
| 隐性代价 | 声望和历史关系可能形成持续请求与义务；“少参与”未必等于有能力拒绝，这是依据后续被强求行为作出的推断。 |
| 未知/反事实 | 若接受更大封赏会怎样，原文不能回答；不能认定自限封赏单独造成其后结果。 |

证据：“臣願封留足矣，不敢當三萬戶。”后来记“呂后乃使建成侯呂澤劫留侯”，又记“留侯行少傅事”。这些是不同时间点，按原文顺序保留。[《史记》卷五十五《留侯世家》，固定版本2666612](https://zh.wikisource.org/w/index.php?title=史記/卷055&oldid=2666612)。

对今天的启发：谈的是具体职责、可拒绝事项、支持资源和回退安排，而非仅仅换一个较轻的职位名称。演示场景中“较小职责”是否可谈成仍是未知。

# 案例三：吴起离魏入楚——换环境可能解决旧问题，又引入新依赖

**节点**：吴起因在魏处境变化而离魏，赴楚任职。该段在《通鉴》安王十五年条内追叙，不据排版擅自精确到离魏之年。

| 项目 | 拆解 |
| --- | --- |
| 当时可得信息 | 原文叙述魏武侯对吴起生疑，吴起惧诛；文本还叙述他人设计，但不能假定吴起当时知道整个设计。 |
| 选项 | 实际去楚有记载；留下澄清、转赴其他国家只是分析重建，史料没有证明这些替代在当时可行。 |
| 所选与判断 | 离魏赴楚。惧诛是原文归于吴起的动因；不能附加未记载的精确收益计算。 |
| 结果 | 到楚受重用并推行措施；同段记贵戚大臣多怨。安王二十一年楚悼王去世后，吴起遭贵戚大臣攻击。 |
| 显性代价 | 放弃原有任职环境、赴另一国家。具体财务成本与家属影响未记。 |
| 隐性代价 | 新角色的支持可能依赖特定掌权者；改革触及利益并累积反对。前者为分析推断，后者有叙述依据。不能说他离魏时就必知后来结果。 |
| 因果边界 | 后来的遭遇还涉及楚国的制度、改革及支持者去世，不能只归因于离魏或“不够低调”。 |

证据：“魏武侯疑之而未信，起懼誅，遂奔楚。”以及“而楚之貴戚大臣多怨吳起者”；后段为“楚悼王薨，貴戚大臣作亂，攻吳起”。[《资治通鉴》卷一《周纪一》安王十五年条与二十一年条](https://zh.wikisource.org/wiki/資治通鑑/卷001)。本次网页未取得固定版本号，保留访问日期2026-09-21与本地快照哈希。

对今天的启发：新机会除了职位与收入，还要看资源、权责和支持是否依赖某一个人。现代组织中的依赖不等同古代人身威胁。

# 现代选项推演

| 路径 | 合适的前提 | 显性与隐性成本 | 观察信号与重评条件 |
| --- | --- | --- | --- |
| 接受晋升 | 收入、职责、实际工时、团队和授权清楚，且符合家庭底线 | 更多时间投入；身份提升带来的随时可用预期；以后退出更难 | 有利：授权资源兑现；不利：职责持续增加、支持缺失；触及预先约定的家庭或健康边界时重评 |
| 争取有边界的角色或先短期试行 | 组织确实允许协商与回退 | 可能少拿收入或机会；边界若只口头约定，责任仍可能外溢 | 看能否明确不负责的事项、谁承接溢出工作、何时复盘；不能达成边界时，不能假装此选项已存在 |
| 维持现状并准备外部机会 | 现状可维持且有精力探索 | 学习和寻找机会的时间；暂缓晋升的机会成本；组织对拒绝晋升的反应未知 | 真实外部机会、现金流储备及可迁移能力明朗后，再判断是否离开 |

本次不估成功率。不同价值排序会改变倾向：若用户把短期收入放首位，且工时成本可承受，接受晋升会更有吸引力；若家庭时间是不可让步的底线，应先核实边界再接受。历史故事不能替用户决定哪个价值更高。

# 条件性启发、风险和下一步

这些案例提示两项待检验机制：当职责和身份带来持续依赖时，仅少要奖赏或换环境未必减少负担；当退出能否成功依赖储备和支持时，离开的理由与离开的能力必须分开评估。它们不是普遍规律或统计结论。

主要风险是把对现代工作的不满升级成历史式猜忌，或只看古人最后的成败、漏掉途中代价与他人的负担。三个精英案例不能代表普通人的所有选择。

最小下一步：列出家庭时间和现金流底线，再向组织核实职责、资源、工时及回退安排；同步核实外部机会，不先假设其存在。新信息取得后再比较三个路径。没有证据时，保留“尚不足以决定”，也是一个合格结论。
